Receipts · ACT-RECEIPT-1.0

Public action receipts

Four fields only: hash, request, output, and event metadata. This is the archive’s receipts paper — not the front page.

Each public action receipt on this host records one requested act, one stated output, the SHA-256 entry hash of that payload, and surface metadata. No user, email, IP, geo, cookies, or tokens.

The chain is insert-only. Significant archive publishes may add a tip here. Sister lattice tabs keep their own tips.

The four fields

What a public receipt holds

ACT-RECEIPT-1.0 publishes exactly these four things.

Hash

entry_hash

SHA-256 of the canonical payload, including the previous hash. The first tip uses a zero previous hash.

Request

One sentence of the act

What was asked: publish a tab, stamp a chain, or record a significant archive act.

Output

One sentence given

What the surface returned. A sentence, not a dump of the page or a private log.

Metadata

Event only

Surface, path, method, status, tool, spec. Never a person, mailbox, or location.
